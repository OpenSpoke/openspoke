# spoke/kubernetes/examples/

Reference Cluster CRs demonstrating how to register a new spoke with
Fleet.

The `spoke-example/` directory is an anonymized template — copy it,
rename it after your spoke, and customize the values to match your
environment (cluster name, labels, kubeconfig source, etc.).

See [`docs/installation/spoke-kubernetes.md`](../../../docs/installation/spoke-kubernetes.md)
for the full spoke onboarding walkthrough.
