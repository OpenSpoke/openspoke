# rancher/manifests/example/

Anonymized reference Rancher instance. Adapt the manifests here to your
environment by customizing:

- hostname / TLS annotations in the Ingress
- image references (if you build a custom Rancher image)
- environment-specific labels and node selectors

See [`docs/installation/rancher.md`](../../../docs/installation/rancher.md)
for the full install walkthrough.
